# ARBO OS — Fase 8: Interfaz de Usuario Administrativa

### 1. Vistas Construidas
1. `/admin/depositos` y `/admin/warehouses` (`Warehouses.jsx`):
   - Selector de sucursal para filtrado ágil.
   - Listado de depósitos habilitados con tipo (`CENTRAL`, `BRANCH`) y estado activo/inactivo.
   - Panel lateral con existencias en tiempo real calculadas desde `inventory_movements`.
   - Modal de alta de nuevo depósito con validación de código único.
2. `/admin/transferencias` y `/admin/transfers` (`StockTransfers.jsx`):
   - Filtro rápido por estado (`DRAFT`, `DISPATCHED`, `RECEIVED`, `CANCELLED`).
   - Listado de remitos con badges de estado y trazabilidad origen/destino.
   - Visor de detalle de transferencia con insumos, cantidad enviada, recibida y snapshot congelado.
   - Modal de nueva transferencia con múltiples líneas dinámicas de insumos.
   - Botón y confirmación de despacho (`DISPATCH`).
   - Modal de recepción con ingreso de cantidades físicas reales y cálculo de discrepancias en tiempo real.
