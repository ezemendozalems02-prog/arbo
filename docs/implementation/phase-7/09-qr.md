# ARBO OS — FASE 7: CAPA FISCAL ARGENTINA & AUTOMATIZACIONES
## 09. ESPECIFICACIÓN DEL CÓDIGO QR FISCAL (RG AFIP 4892/2020)

---

## 1. NORMATIVA Y PROTOCOLO
Todo comprobante fiscal electrónico emitido en la República Argentina debe exhibir un código QR oficial. Al ser escaneado por el consumidor o un inspector, debe redirigir a los servidores de AFIP con un parámetro Base64:

```
https://www.afip.gob.ar/fe/qr/?p={BASE64_PAYLOAD}
```

## 2. ESTRUCTURA DEL PAYLOAD JSON
El JSON subyacente codificado contiene estrictamente:
```json
{
  "ver": 1,
  "fecha": "YYYY-MM-DD",
  "cuit": 30712345678,
  "ptoVta": 1,
  "tipoCmp": 6,
  "nroCmp": 1042,
  "importe": 3500.00,
  "moneda": "PES",
  "ctz": 1,
  "tipoDocRec": 99,
  "nroDocRec": 0,
  "tipoCodAut": "E",
  "codAut": 74289123456789
}
```

## 3. SEPARACIÓN DE RESPONSABILIDADES
- **`qrGenerator.js`**: Genera el payload JSON oficial, realiza el formateo Base64 y construye la URL canónica.
- **Capa UI**: Renderiza visualmente el QR utilizando bibliotecas vectoriales SVG, o link directo en el comprobante digital.
