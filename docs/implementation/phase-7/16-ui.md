## 2. PANTALLA ADMIN — DASHBOARD FISCAL & AUTOMATIZACIONES
Ubicación: `src/admin/pages/fiscal/FiscalDashboard.jsx`.
Ruta: `/admin/fiscal`.
Pestañas operativas:
1. **Comprobantes**: Grilla con listado de facturas emitidas, desglose de Neto, IVA, Total, estado de CAE y enlace de validación QR AFIP.
2. **Cola de Contingencia**: Monitor de comprobantes demorados, conteo de reintentos, diagnóstico de error de conexión y botón de resolución manual.
3. **Automatizaciones**: Visualización de reglas activas y auditoría de ejecuciones con sus claves de idempotencia.
4. **Parámetros AFIP / ARCA**: CUIT emisor, condición tributaria, Punto de Venta activo y límite de timeout.
